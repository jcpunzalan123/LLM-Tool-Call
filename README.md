**Tool Calling in LLM Demonstration**
=====================================

A Python script demonstrating tool calling in Large Language Models (LLMs).

**Introduction**
---------------

This project demonstrates a simple way to call external tools from within a Large Language Model (LLM) using
Python. It provides two functions: `get_stock_price` and `get_current_weather`, which make API calls to retrieve
stock prices and current weather conditions respectively.

**Requirements**
----------------

* Python
* Ollama (for LLM interactions)
* requests library (for HTTP requests)
* Yahoo Finance API

**Installation**
--------------
To install the project, follow these steps:

1. Clone the repository: `git clone https://github.com/jcpunzalan123/LLM-Tool-Call.git`
2. Install dependencies: `pip install -r requirements.txt`

**Usage**
---------

1. Update the value of the variable 'prompt' in line 22 of the main.py
2. Run the python script by inputting the following command in the terminal: "python main.py"
